# Maynard K. Nay-osan — Animated Portfolio

## Files
- `index.html` — page structure and portfolio content
- `css/style.css` — layout, themes, responsive styles, and hover animations
- `js/main.js` — section navigation, theme switching, animated smoke, and pointer effects
- `assets/profile.jpg` — profile photo extracted from your supplied portfolio HTML

## Publish with GitHub Pages
1. Download and extract this ZIP.
2. Open your GitHub portfolio repository.
3. Upload the contents of this folder (not the enclosing folder) to the repository root.
4. Keep the folder structure exactly as shown.
5. Commit the changes. If GitHub Pages is already enabled for `main` and `/(root)`, the site will update automatically.

## Notes
- The animated smoke is rendered with WebGL and reacts subtly around the mouse pointer.
- The smoke palette blends between dark and light themes.
- A custom cursor halo is enabled only on desktop/fine-pointer devices.
- Reduced-motion preferences and touch devices automatically disable the custom cursor.
- Google Fonts are loaded from Google Fonts; the rest of the site runs as static files.
